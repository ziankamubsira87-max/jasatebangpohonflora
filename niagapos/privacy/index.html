Kebijakan Privasi

NIAGA POS Backup

Terakhir diperbarui: 23 November 2026

Kebijakan ini menjelaskan bagaimana NIAGA POS Backup menggunakan informasi untuk membuat salinan database NIAGA POS ke Google Drive yang diotorisasi oleh pemilik outlet.

1. Informasi yang diproses

Proses pencadangan menyalin database NIAGA POS. Database tersebut dapat memuat data transaksi, pembayaran, produk, pelanggan, pengeluaran, pengguna, dan pengaturan outlet yang tersimpan di sistem. File backup juga dapat memuat informasi bisnis atau pribadi yang sebelumnya dimasukkan pengguna ke dalam NIAGA POS.

2. Penggunaan Google Drive

Jika pengguna menghubungkan Google Drive, NIAGA POS Backup menggunakan otorisasi Google untuk membuat dan mengelola file backup di akun Drive yang dipilih. Integrasi dirancang menggunakan cakupan akses file yang dibuat atau dibuka oleh aplikasi, bukan untuk membaca seluruh file pribadi pengguna di Google Drive.

Data Google digunakan hanya untuk menjalankan pencadangan yang diminta pengguna. Data tersebut tidak dijual, disewakan, atau digunakan untuk iklan.

3. Penyimpanan dan keamanan

File backup disimpan di Google Drive milik akun yang diotorisasi. Kredensial dan konfigurasi teknis yang diperlukan untuk menjalankan workflow disimpan sebagai secrets pada layanan GitHub Actions, bukan ditampilkan di halaman publik. Pengguna tetap bertanggung jawab menjaga keamanan akun Google, GitHub, dan akses ke perangkatnya.

Pengiriman, penyimpanan, dan pemrosesan juga tunduk pada kebijakan keamanan serta ketentuan layanan penyedia infrastruktur terkait, termasuk Google, GitHub, dan Supabase.

4. Retensi dan penghapusan

File backup di Google Drive tetap tersimpan sampai pemilik akun menghapusnya atau sampai kebijakan retensi yang kelak diterapkan menghapusnya. Pemilik akun dapat menghapus file backup langsung dari Google Drive. Artefak workflow GitHub Actions memiliki masa simpan terbatas sesuai konfigurasi workflow.

5. Pembagian data

NIAGA POS Backup tidak menjual data pengguna. Data diproses oleh penyedia infrastruktur yang diperlukan untuk menjalankan aplikasi dan pencadangan. Akses ke file backup juga dapat diberikan oleh pemilik akun melalui fitur berbagi Google Drive.

6. Pilihan dan hak pengguna

  • Pengguna dapat tidak menghubungkan Google Drive; pencadangan Drive tidak akan berjalan tanpa otorisasi.
  • Pengguna dapat mencabut akses aplikasi melalui pengaturan keamanan akun Google.
  • Pengguna dapat menghapus file backup dari Google Drive miliknya.
  • Pengguna dapat menghubungi pengelola untuk pertanyaan atau permintaan terkait privasi.

7. Privasi anak

NIAGA POS Backup ditujukan untuk penggunaan operasional bisnis dan bukan ditujukan kepada anak-anak.

8. Perubahan kebijakan

Kebijakan ini dapat diperbarui apabila cara kerja aplikasi atau ketentuan yang berlaku berubah. Versi terbaru akan dipublikasikan pada halaman ini beserta tanggal pembaruannya.
